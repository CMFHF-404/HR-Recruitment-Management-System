## 覆盖场景

- 管理员登录成功。
- 用户名或密码错误时返回失败提示。
- 新增岗位并获得岗位编号。
- 新增候选人并关联岗位。
- 更新候选人的简历筛选状态。
- 安排候选人面试。
- 登记候选人录用结果。
- 查询候选人完整招聘进度。
- 岗位已有候选人时禁止删除。
- 统计接口正确返回录用人数。

## 手工验收建议

1. 使用 `admin / admin123` 登录系统。
2. 在岗位管理中新增一个招聘岗位。
3. 在候选人管理中新增候选人，并选择该岗位。
4. 在招聘流程中依次更新筛选、面试和录用状态。
5. 回到统计首页，确认各项统计数据发生变化。
