# 《小型企业招聘管理信息系统的设计与实现》课程设计报告

## 一、系统概述

本系统面向小型企业 HR 管理人员，围绕招聘流程中的岗位发布、候选人登记、简历筛选、面试安排、录用结果登记和数据统计进行信息化管理。系统采用前后端分离架构，后端提供 REST API，前端提供浏览器管理界面。

## 二、需求分析

系统主要用户为企业 HR 管理员。核心业务流程为：岗位发布 → 候选人登记 → 简历筛选 → 面试安排 → 面试结果记录 → 录用结果管理 → 数据统计。

主要功能包括：

- 管理员登录
- 岗位信息增删改查
- 候选人信息增删改查
- 简历筛选状态维护
- 面试安排与评价记录
- 录用结果登记
- 招聘数据统计

## 三、系统设计

系统采用 Spring Boot + Vue 的前后端分离架构：

- 后端负责身份认证、业务校验、数据库访问和统计接口。
- 前端负责登录、导航、表格管理、表单录入和图表展示。
- 数据库使用 MySQL，测试环境使用 H2。

模块划分：

- 登录模块：管理员账号密码验证，登录成功后返回 JWT。
- 岗位管理模块：维护岗位名称、部门、招聘人数、要求和状态。
- 候选人管理模块：维护候选人基本信息并关联岗位。
- 简历筛选模块：维护待筛选、通过、未通过状态。
- 面试安排模块：维护面试时间、地点、面试官、状态和评价。
- 录用管理模块：维护待定、录用、未录用、放弃入职状态。
- 查询统计模块：统计岗位数、候选人数、待筛选数、面试人数和录用人数。

## 四、系统实现

后端统一接口前缀为 `/api`。除登录接口外，其他接口均需要携带 JWT。系统使用统一响应结构：

```json
{
  "success": true,
  "message": "success",
  "data": {}
}
```

前端使用 Element Plus 构建管理界面，使用 Axios 调用后端接口，使用 ECharts 展示各岗位候选人数、面试人数和录用人数。

## 五、测试结果

后端自动化测试覆盖登录失败、完整招聘流程、岗位删除限制和统计接口。前端通过生产构建验证。手工验收可按照 `docs/test-record.md` 的步骤完成。

## 六、总结

本系统实现了小型企业招聘流程的基本信息化管理，功能结构清晰，数据表关系明确，能够满足课程设计中对管理信息系统需求分析、数据库设计、功能实现和测试验证的要求。
